## 🤖 AI × Cloud

| Focus area | How I apply it |
|---|---|
| **Generative AI on AWS** | Amazon Bedrock and Amazon Q for internal assistants, knowledge search (RAG) and runbook help |
| **AIOps** | Using LLMs to summarise logs and alerts, triage incidents and suggest fixes, on top of CloudWatch and Grafana |
| **AI-assisted migration** | Automating discovery, dependency mapping and wave planning with AI, then executing with AWS MGN and DMS |
| **Platforms for AI workloads** | Landing zones, IAM guardrails and private networking for AI services; GPU and inference capacity on EKS and SageMaker |
| **FinOps for AI** | Visibility and controls for GPU, model-hosting and token spend, applying FinOps practices to AI costs |
| **Responsible AI in the enterprise** | Data privacy, access control and governance for AI services in regulated environments |

## 🛠️ What I work on

- **Cloud migration** — discovery, wave planning and rehost/replatform with AWS MGN and DMS
- **Landing zones & governance** — AWS Control Tower, multi-account setup, IAM guardrails
- **Infrastructure as Code** — Terraform, Ansible, CloudFormation
- **CI/CD & containers** — Jenkins, GitHub Actions, Docker, Kubernetes (EKS)
- **FinOps** — cost visibility, rightsizing and showback for cloud spend
- **Observability & AIOps** — Elasticsearch, Grafana, CloudWatch, with AI-assisted alert triage
